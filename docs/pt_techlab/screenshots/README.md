# Фото прототипа ТАКТ — для каталога

Снимки сделаны с рабочего места аналитика ТАКТ, подключённого к боевому стенду
`ralta.ru/takt_pt_arm/` (44 демонстрационных дела). Интерфейс и данные — те же, что
на живом стенде и в демонстрационном ролике презентации.

Ширина 3360 пикселей, двойная плотность — снимки пригодны и для печати, и для экрана.
Имена файлов латиницей: адреса ссылок на них остаются читаемыми.

**Данные синтетические.** Демонстрационный сценарий INC-002 «компрометация конвейера
сборки через фишинг»: 1030 событий четырёх классов источников, 27 из них — цепочка
атаки. На реальном объекте эти события не наблюдались; узлы, учётные записи и адреса
вымышлены.

| Файл | Что на снимке |
|---|---|
| `01-analyst-workstation.png` | **Рабочее место аналитика.** Общий вид: очередь инцидентов, карточка дела, панель сущности и находок. Так аналитик видит смену целиком |
| `02-case-card-and-verdict.png` | **Карточка дела и вердикт.** Класс риска и балл, вердикт «не определено», перечень недостающего организационного контекста, состав по источникам, сработавшие правила, расширение разбора до узла |
| `03-event-chain.png` | **Цепочка событий.** Таблица событий дела: время, основание включения, источник, операция, узел, учётная запись, процесс. Отсюда аналитик отделяет события от инцидента и заводит находки |
| `04-attack-graph.png` | **Граф атаки.** 14 сущностей, 19 связей, воспроизведение по шагам. Построен только по событиям этого дела |
| `05-entity-links.png` | **Связи сущностей.** Кто к кому обращался, кто что запустил и выполнил |
| `06-entity-card.png` | **Карточка сущности.** Историчность узла (частота в истории, разброс во времени, первое и последнее появление), источники, связанные инциденты, окружение |
| `07-attack-chain-simulation.png` | **Симуляция цепочки атаки.** Плеер по фазам, шкалы времени и шагов, граф сущностей, разбор шагов |
| `08-chain-reconstruction.png` | **Реконструкция цепочки.** Точка входа как гипотеза, разбор по событиям с указанием оснований и оговоркой, что связь по времени и узлу не означает причинности |
| `09-response-package.png` | **Пакет реагирования.** Рекомендованные действия по узлам, учётным записям и адресам. Внизу — граница продукта: «ТАКТ не выполняет эти действия и не отправляет команды. Исполняет внешняя система после подтверждения аналитика» |

На снимках 08 и 09 разделы карточки, лежащие выше, свёрнуты — так же, как их сворачивает
аналитик, когда работает с одним разделом. Содержимое самих разделов не менялось.
