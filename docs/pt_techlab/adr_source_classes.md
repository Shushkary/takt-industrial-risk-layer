# ADR-001: четыре класса источников SOC

- Статус: **предложено, ожидает решения заказчика**
- Дата: 2026-07-10

## Контекст

Требуются минимум четыре разнородных класса источников и единый механизм расследования. TAKT уже содержит OT-конвейер и каталог промышленных инвариантов.

## Решение

Принять EDR, SIEM, NDR и промышленную телеметрию OT/PT ISIM. Первые три класса покрывают конечную точку, агрегированный SOC-контекст и сеть; OT сохраняет промышленную специализацию TAKT. Все адаптеры реализуют один потоковый порт, сохраняют сырой payload и выдают общий SOC-профиль события.

## Рассмотренные варианты

- Service Desk вместо OT: полезен для контекста, но слабее покрывает наблюдаемую атаку и не использует OT-инварианты TAKT.
- Threat Intelligence вместо OT: даёт обогащение артефактов, но не является первичной телеметрией. Использовать в Спринте 5.
- Четыре продукта одного типа: отклонено, поскольку не даёт междоменной корреляции.

## Риски отсутствия данных

| Недоступный класс | Потеря | Допустимая деградация |
|---|---|---|
| EDR | процессы, хеши, локальный пользователь | SIEM/NDR корреляция по узлу и адресу; пометка неполной наблюдаемости |
| SIEM | правила и агрегированный контекст | прямые EDR/NDR/OT события; без наследования SIEM-вердикта |
| NDR | независимое подтверждение сетевого распространения | адреса из EDR/SIEM; снижение уверенности |
| OT/PT ISIM | технологический контекст и инварианты | SOC-функции работают; OT-сценарий объявляется неполным |

Ни один пропуск не заполняется синтетическими фактами. Доля доступных источников и причины деградации должны быть видны аналитику.
