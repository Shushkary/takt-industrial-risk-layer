## Что это

Рабочее место аналитика SOC поверх единого хранилища заказчика: приём событий из ≥ 4 классов источников (EDR, SIEM, NDR/NTA, промышленная телеметрия), автоматическая корреляция по сущностям (узел, пользователь, процесс, адрес, артефакт), карточки сущностей с историчностью и окружением, журнал находок, реконструкция цепочки атаки, обогащение артефактов, пакет реагирования и отчёт по инциденту. Действует принцип **human-in-the-loop**: критичные действия по реагированию система не выполняет автоматически, финальное решение — за аналитиком.
