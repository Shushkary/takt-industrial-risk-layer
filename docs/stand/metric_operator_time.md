# Метрика: время обработки инцидента оператором

> **Исторический документ.** Описывает демонстрационный стенд со сценарием
> «котельная / IEC-104». Актуальный сценарий демонстрации — INC-002
> (компрометация конвейера сборки), см.
> [`docs/pt_techlab/prototype.md`](../pt_techlab/prototype.md).


**Сценарий:** Цепочка IEC-104: несанкционированная команда управления на ПЛК

**Набор данных стенда:** 486 событий в сыром потоке, из них 6 — реальная цепочка атаки (1.2% сигнала), 4 источника, 5 узла графа атаки.

## Итог

| Режим | Время обработки |
|---|---|
| 🖐️ Полностью ручной | **29 мин 45 с** (1785 с) |
| ⚡ Режим ТАКТ | **2 мин 55 с** (175 с) |
| **Экономия** | **26 мин 50 с**, ускорение **×10.2** |

## Ручной режим — из чего складывается время

| Этап | Секунды |
|---|---|
| Просмотр сырого потока | 765 |
| Переключение между источниками | 360 |
| Ручная корреляция цепочки | 360 |
| Оформление вывода | 300 |

## Режим ТАКТ — из чего складывается время

| Этап | Секунды |
|---|---|
| Чтение XAI-резюме | 40 |
| Проверка графа атаки | 60 |
| Проверка baseline (z-score) | 30 |
| Решение и подтверждение | 45 |

## Допущения модели

Модель параметрическая и воспроизводимая (см. `stand/benchmark.py`). Числа основаны на типовых значениях triage в SOC. Во фронтенде на экране «Сравнение» есть живой секундомер — фактическое время конкретного оператора измеряется на тех же данных стенда.
