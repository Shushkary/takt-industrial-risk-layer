# Демонстрационный стенд и выкладка

Документы по развёртыванию АРМ и по демонстрационному стенду. Перенесены из
рабочих каталогов на диске, чтобы не жить копиями вне репозитория.

| Документ | Статус |
|---|---|
| [`deploy_ralta_current.md`](deploy_ralta_current.md) | **Актуальный** порядок выкладки на `ralta.ru`: разведка, бэкапы, проверки, откат |
| [`deploy_stand_vm.md`](deploy_stand_vm.md) | Историческая инструкция развёртывания стенда в Docker |
| [`deploy_ralta_legacy.md`](deploy_ralta_legacy.md) | Историческая инструкция выкладки на `ralta.ru/TAKT_PT` |
| [`stand_readme.md`](stand_readme.md) | Описание демонстрационного стенда со сценарием «котельная / IEC-104» |
| [`metric_operator_time.md`](metric_operator_time.md) | Измерение времени обработки инцидента оператором: ручной режим против режима ТАКТ |

Актуальный сценарий демонстрации — **INC-002** (компрометация конвейера сборки
через фишинг), см. [`docs/pt_techlab/prototype.md`](../pt_techlab/prototype.md).
Документы со сценарием «котельная» сохранены как история: они описывают
предыдущую версию стенда и метрику, снятую на нём.

Правило одной редакции: источник правды — этот репозиторий. Файлы приложения
не правятся напрямую на сервере, выкладка выполняется с явного согласия
владельца и после резервной копии.
