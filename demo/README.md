# ТАКТ — демонстрационная версия для тестирования

Автономный стенд: ядро ТАКТ (REST API), сборщик инцидентов и АРМ аналитика.
Разворачивается одной командой в Docker, работает без доступа в интернет после
сборки образа, данных наружу не передаёт.

Версия: см. `MANIFEST.json` (поле `version`).

---

## 1. Что нужно на машине

| Требование | Значение |
|---|---|
| Docker Engine | 24.0 и новее |
| Docker Compose | v2 (команда `docker compose`, без дефиса) |
| Свободные порты | `8080` (АРМ), `8090` (API) — публикуются только на `127.0.0.1` |
| Диск | ~1,5 ГБ под образ и данные |
| ОС | Linux, Windows с Docker Desktop, macOS |

Сборка образа скачивает базовый образ `python:3.13-slim-bookworm`, `nginx:1.27-alpine`
и пакеты Python. Если машина без доступа в интернет — см. раздел 7.

## 2. Запуск

Из каталога, куда распакован архив:

```bash
docker compose up -d --build
```

Первая сборка занимает 3–6 минут. Готовность:

```bash
docker compose ps
curl -s http://127.0.0.1:8090/ready
```

Ожидаемый ответ: `{"ready":true,"case_storage":"sqlite",...}`.

## 3. Заполнение демонстрационными данными

```bash
docker compose run --rm seed
```

Скрипт загружает выгрузки четырёх классов источников, собирает инцидент и
добавляет синтетическую цепочку. Занимает 1–3 минуты, в конце печатает список
собранных дел.

Повторный запуск отклоняется — иначе события попали бы в хранилище вторым
экземпляром. Чистый прогон: `docker compose down -v && docker compose up -d --build`.

## 4. Что открыть

| Адрес | Что это |
|---|---|
| http://127.0.0.1:8080/ | **АРМ аналитика** — основной интерфейс |
| http://127.0.0.1:8090/docs | Swagger: полный контур REST API |
| http://127.0.0.1:8090/health | Состояние сервиса |
| http://127.0.0.1:8090/catalog/vocabulary | Словарь обозначений (класс риска, вердикт, источник) |

### Порядок проверки в АРМ

1. **Очередь дел** — список инцидентов, отсортированный по риску. Сверху два
   собранных инцидента, ниже — фоновые дела по отдельным срабатываниям.
2. **Расследование** — открыть инцидент с наибольшим риском:
   - «Принято от автоматики» — что закрыли правила SIEM, что осталось аналитику;
   - «Обоснованность вывода» — из чего складывается достоверность и чего не хватает;
   - «Почему это инцидент» — объяснение (XAI) по конкретному делу;
   - «Что отменит вердикт» — проверки, способные опровергнуть гипотезу;
   - «Уровни сущности» — переход адрес → узел → учётная запись → процесс → артефакт.
3. **Цепочка атаки** — реконструкция по фазам kill chain.
4. **Пакет реагирования** — список вариантов с последствиями. Ни один вариант не
   выполняется автоматически (см. раздел 6).
5. **Доказательный пакет** — выгрузка с контрольными значениями и манифестом;
   повторный прогон на тех же данных даёт тот же вердикт и то же агрегированное
   контрольное значение.
6. **Отчёты** — паспорт инцидента и сводка для руководителя в PDF.

### Проверка через API

```bash
curl -s "http://127.0.0.1:8090/cases?limit=5&sort=risk_score_desc"
```

```bash
curl -s "http://127.0.0.1:8090/cases/<case_id>/attack-chain"
```

```bash
curl -s "http://127.0.0.1:8090/events/search?host_id=ws-17&limit=20"
```

## 5. Демонстрационные данные — что именно загружается

**Все данные синтетические.** Ни одно событие не наблюдалось на реальном объекте.
Числовые характеристики продукта на этих данных не измеряются — стенд показывает
работу контура, а не производительность на боевом потоке.

### Сценарий 1 — INC-002: компрометация конвейера сборки через фишинг

1030 событий четырёх классов источников (EDR, SIEM, NDR, промышленная телеметрия),
из них цепочку атаки составляют 27. Ход: фишинг на `ws-17` под учётной записью
`smirnov` → канал управления к `185.220.101.34` → захват служебной учётной записи
`svc_build` → перемещение на `build-srv-01` → неподписанный артефакт в конвейере
`release-prod`.

Проверка на ложные срабатывания встроена в датасет: три отвлекающие аномалии —
администратор вне рабочего окна, санкционированный сканер, ночное резервное
копирование — внешне похожи на атаку и **в инцидент не попадают**. В АРМ они
видны отдельными делами со статусом «требует проверки».

Описание формата и разметки — `seed/inc_002/README_INC-002.md` и
`seed/inc_002/data_contract_INC-002.md`.

### Сценарий 2 — захват инженерной станции и остановка линии розлива

59 событий, девять фаз kill chain, четыре класса источников. Написан так, чтобы
было видно межсистемное сведение: шесть отличительных сущностей (адрес, три
учётные записи, хеш инструмента, домен канала управления) встречаются в разных
фазах и в разных источниках — именно их аналитик переносил бы руками между
консолями. Заголовок дела содержит пометку о синтетичности.

## 6. Границы решения — что стенд намеренно не делает

- ТАКТ **не выполняет критичные действия автоматически**: не блокирует, не
  изолирует, не останавливает контроллеры, не меняет конфигурацию оборудования и
  не закрывает инциденты без оператора. Пакет реагирования — это рекомендации;
  исполняет их внешняя система после подтверждения аналитика.
- В интерфейсе и API **нет** ни одного эндпоинта активного управления оборудованием.
- ТАКТ **не является СКЗИ**. В демонстрационном режиме целостность доказательного
  пакета подтверждается контрольными значениями и манифестом — это проверяемая
  целостность, **не** КЭП. Подпись по ГОСТ выполняет внешний сертифицированный
  сервис, подключаемый отдельно.
- Полный текст границ — `docs/product_boundary.md` (открывается и из пояснений в АРМ).

## 7. Машина без доступа в интернет

Соберите образы на машине с доступом и перенесите их файлами:

```bash
docker compose build && docker pull nginx:1.27-alpine
```

```bash
docker save takt-demo-api nginx:1.27-alpine -o takt-demo-images.tar
```

На изолированной машине, рядом с распакованным пакетом:

```bash
docker load -i takt-demo-images.tar
```

```bash
docker compose up -d
```

```bash
docker compose run --rm seed
```

Флаг `--build` на изолированной машине не нужен: образы уже загружены.

## 8. Проверка ключа API

Стенд поднят без проверки ключа и слушает только петлевой адрес. Чтобы включить
проверку, задайте в `docker-compose.yml` у сервисов `api`, `assembly` и `seed`:

```yaml
      TAKT_AUTH_REQUIRED: "1"
      TAKT_API_KEY: "<ваш ключ>"
```

и уберите строку `TAKT_PROFILE: dev`. После `docker compose up -d` АРМ запросит
ключ при первом обращении — он вводится в интерфейсе и уходит в заголовке
`X-TAKT-API-Key`. Полный перечень переменных окружения и периметр безопасности —
`docs/configuration.md`.

## 9. Остановка и удаление

```bash
docker compose down
```

```bash
docker compose down -v
```

Первая команда останавливает стенд и сохраняет данные, вторая удаляет и данные.
Удалить образ: `docker rmi takt-demo-api`.

## 10. Если что-то не так

| Симптом | Причина и что делать |
|---|---|
| `api` в состоянии `starting` дольше минуты | Смотрите `docker compose logs api`: чаще всего не хватает прав на том с данными |
| АРМ открылся, но список дел пуст | Засев не выполнялся: `docker compose run --rm seed` |
| Дела появились, инцидентов нет | Не поднят сборщик: `docker compose ps assembly`, логи `docker compose logs assembly` |
| В АРМ «нет связи с API» | Проверьте `curl http://127.0.0.1:8090/ready`; если API отвечает, смотрите `docker compose logs arm` |
| Порт занят | Измените левую часть в `ports:` (например `127.0.0.1:18080:80`) и откройте новый адрес |
| Ссылка из пояснения в АРМ даёт 404 | В пакет входит выборка документов; полный состав — в `MANIFEST.json` |

## 11. Состав пакета

| Путь | Что это |
|---|---|
| `docker-compose.yml`, `Dockerfile`, `nginx.arm.conf` | Развёртывание стенда |
| `src/`, `config/`, `pyproject.toml` | Ядро ТАКТ: домен, движки, инварианты, API |
| `arm/` | АРМ аналитика (статический интерфейс) |
| `seed/` | Скрипт засева и демонстрационные данные |
| `docs/` | Документы, на которые ссылаются пояснения в интерфейсе |
| `MANIFEST.json`, `SHA256SUMS` | Состав пакета и контрольные суммы файлов |

Проверка целостности пакета на Linux/macOS:

```bash
sha256sum -c SHA256SUMS
```

На Windows:

```powershell
Get-Content SHA256SUMS | ForEach-Object { $p = $_ -split '  ', 2; $h = (Get-FileHash -Algorithm SHA256 $p[1]).Hash.ToLower(); if ($h -ne $p[0]) { "РАСХОЖДЕНИЕ: " + $p[1] } }
```
