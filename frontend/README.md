# TAKT АРМ — Frontend автоматизированного рабочего места SOC-оператора

Современный веб-интерфейс для работы с инцидентами информационной безопасности, построенный на React 18 + TypeScript + Vite.

## Возможности

### 🎯 Очередь инцидентов
- Live-обновления через SSE (Server-Sent Events)
- Фильтрация по severity и статусу
- Анимированное появление/изменение кейсов (Framer Motion)
- Keyboard-first навигация: `j`/`k` для перемещения, `Enter` для открытия

### 🔍 Рабочий стол кейса
- **Трёхпанельный layout:**
  - Левая панель: контекст кейса, находки, статус
  - Центральная панель: вкладки Граф/Таймлайн/События
  - Правая панель: карточка выбранной сущности с sparkline типичности

### 📊 Граф атаки (React Flow)
- Типизированные узлы (host/user/process/address/artifact) с иконками
- Цветовое кодирование по severity
- Клик по ребру → причина корреляции (объяснимость)
- Режим «Проиграть атаку» — пошаговая анимация цепочки атаки

### ⏱️ Таймлайн (visx)
- Дорожки по классам источников
- Zoom/Brush для детального просмотра
- Синхронизация с графом

### 🎨 Дизайн
- Тёмная тема SOC-стандарт
- WCAG 2.1 AA контрастность
- Поддержка `prefers-reduced-motion`

## Быстрый старт

### Локальная разработка

```bash
# Установка зависимостей
npm ci

# Запуск dev-сервера (http://localhost:3000)
npm run dev

# Production build
npm run build

# Предпросмотр production build
npm run preview
```

### Конфигурация

Создайте `.env` файл (см. `.env.example`):

```env
VITE_TAKT_API_BASE_URL=http://127.0.0.1:8090
```

### Docker Compose

Запуск frontend + backend одной командой:

```bash
# Из корня репозитория
docker compose up --build

# Frontend доступен на http://localhost:3000
# Backend API на http://localhost:8090
```

## Стек технологий

| Библиотека | Назначение |
|-----------|-----------|
| **React 18** | UI framework |
| **TypeScript** | Типизация |
| **Vite** | Сборщик |
| **React Router** | Маршрутизация |
| **TanStack Query** | Управление серверным состоянием, кэширование |
| **Zustand** | Клиентское состояние |
| **React Flow** | Интерактивный граф атаки |
| **visx** | Таймлайн и визуализации |
| **Framer Motion** | Анимации |
| **Radix UI** | Доступные компоненты (Tabs, Dialog, Select) |
| **date-fns** | Работа с датами |

## Структура проекта

```
src/
├── api/          # API клиент (fetch + TanStack Query)
├── stores/       # Zustand stores (фильтры, выбранные сущности)
├── screens/      # Основные экраны (IncidentQueue, CaseWorkbench)
├── components/   # Переиспользуемые компоненты
├── styles/       # Дизайн-токены, тема
├── types/        # TypeScript интерфейсы
├── App.tsx       # Корневой компонент с роутингом
└── main.tsx      # Точка входа
```
