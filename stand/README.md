# Стенд TAKT — синтетические данные + АРМ SOC-оператора

Полностью рабочая демонстрационная связка: **синтетический API стенда** + **фронтенд АРМ**.
Показывает ключевую метрику проекта — **время обработки данных оператором** — в двух режимах:
**полностью ручном** и **в режиме ТАКТ**.

Сценарий данных — многошаговая атака на АСУ ТП подстанции по протоколу **IEC-104**:
сканирование периметра → brute-force → вход на инженерную АРМ → доставка импланта →
команда управления `C_SC_NA_1` на ПЛК → аномалия телеметрии HMI. Реальная цепочка из
6 событий «спрятана» среди ~480 шумовых — именно это оператор разбирает вручную.

## Как открыть фронтенд

### Вариант 1 — Docker (рекомендуется, одна команда)

```bash
docker compose -f docker-compose.stand.yml up --build
```

После запуска откройте в браузере:

| Что | Адрес |
|---|---|
| **АРМ — очередь инцидентов** | http://localhost:3000 |
| **Экран «Сравнение» (метрика оператора)** | http://localhost:3000/compare |
| API стенда (Swagger) | http://localhost:8090/docs |

Остановить: `Ctrl+C`, затем `docker compose -f docker-compose.stand.yml down`.

### Вариант 2 — без Docker (локально)

Терминал 1 — API стенда:
```bash
cd stand
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8090
```

Терминал 2 — фронтенд (режим разработки):
```bash
cd frontend
npm install
npm run dev        # откроется http://localhost:5173
```
Либо production-сборка:
```bash
cd frontend
npm run build && npm run preview   # http://localhost:4173
```

Фронтенд по умолчанию обращается к API стенда на `http://localhost:8090`
(CORS открыт). Переопределить: переменная `VITE_TAKT_API_BASE_URL`.

## Экран «Сравнение» — как читать

Открывается по кнопке **«⏱ Сравнение: ручной режим vs ТАКТ»** в очереди инцидентов
или по адресу `/compare`.

- **Сверху** — итоговая метрика (оценка модели): ручной режим ≈ 30 мин, режим ТАКТ ≈ 3 мин,
  ускорение ≈ ×10.
- **Слева «Полностью ручной режим»** — сырой нескоррелированный поток из SIEM.
  Нажмите **«Начать разбор»** — пойдёт секундомер. Нужно вручную найти все 6 событий
  атаки среди шума (кликните по строкам уровня `ALERT`/`NOTICE`).
- **Справа «Режим ТАКТ»** — готовый коррелированный кейс: XAI-резюме, граф атаки,
  baseline сущности (z-score). Нажмите **«Начать разбор»**, проверьте и нажмите
  **«Подтвердить инцидент»** — секундомер остановится.

Секундомеры позволяют измерить **фактическое** время конкретного оператора на одних и тех
же данных стенда, а верхние карточки дают априорную оценку по параметрической модели
(`stand/benchmark.py`, отчёт — `docs/METRIC_OPERATOR_TIME.md`).

## Состав стенда

| Файл | Назначение |
|---|---|
| `synthetic_data.py` | Детерминированный генератор данных (кейсы, события, граф атаки, baseline, сырой поток) |
| `server.py` | FastAPI-сервер, отдаёт контракт `/api/v1/*` фронтенда + SSE + метрику |
| `benchmark.py` | Параметрическая модель времени оператора (ручной vs ТАКТ) |
| `Dockerfile`, `requirements.txt` | Контейнеризация стенда |

## Эндпоинты API стенда

```
GET   /api/v1/cases                      список кейсов
GET   /api/v1/cases/{id}                  кейс
PATCH /api/v1/cases/{id}                  смена статуса
GET   /api/v1/cases/{id}/attack-chain     граф атаки
GET   /api/v1/cases/{id}/events           события кейса
GET   /api/v1/events/search               поиск (курсорная пагинация)
GET   /api/v1/baseline/{type}/{id}        baseline (z-score sparkline)
GET   /api/v1/stream/cases                SSE-поток новых кейсов
GET   /api/v1/raw-events                  сырой поток для ручного режима
GET   /api/v1/benchmark                   метрика: время оператора (JSON)
GET   /api/v1/benchmark.md                та же метрика в Markdown
GET   /health                             проверка живости
```
